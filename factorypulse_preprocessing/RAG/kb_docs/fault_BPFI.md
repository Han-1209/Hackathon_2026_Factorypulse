# 軸承內圈故障（BPFI）

> 緊急程度：高　｜　適用資料集：變負載、變轉速
> 是否需要「立即」停機由規則引擎依風險等級判定，本文件不決定。

## 軸承內圈故障｜說明

適用狀況：軸承內圈故障（BPFI）

振動出現與內圈缺陷特徵頻率相符的週期性衝擊，通常代表內滾道已有剝落或裂紋。

## 軸承內圈故障｜判斷依據（本系統實測訊號特徵）

適用狀況：軸承內圈故障（BPFI）

包絡譜在內圈通過頻率 BPFI（本機台為轉頻的 5.36 倍，3010 RPM 下約 268.8 Hz）出現明顯譜線，實測可達正常值的 20 倍。內圈隨軸旋轉、缺陷週期性進出承載區，因此譜線常伴隨 ±1 倍轉頻的邊帶。

## 軸承內圈故障｜可能原因

適用狀況：軸承內圈故障（BPFI）

- 疲勞剝落
- 潤滑不足或油脂劣化
- 異物侵入
- 安裝時內圈受力不當

## 軸承內圈故障｜建議檢查項目

適用狀況：軸承內圈故障（BPFI）

- 軸承座溫度與異音
- 潤滑脂狀態與補充紀錄
- 軸承與軸的配合公差

## 軸承內圈故障｜待修事項

適用狀況：軸承內圈故障（BPFI）

- 排程停機更換軸承（是否需立即停機依風險等級判定）
- 檢查潤滑系統
- 確認安裝方式是否造成偏載

## 軸承內圈故障｜需要工具

適用狀況：軸承內圈故障（BPFI）

- 軸承拔卸器（three-jaw puller）或油壓拔卸工具
- 軸承加熱器（感應式，安裝新軸承用，避免敲擊）
- 扭力扳手
- 百分表與磁性座（確認軸的偏擺）
- 內外徑量具（確認軸與軸承座公差）
- 測振筆或手持振動分析儀（修後複測）

## 軸承內圈故障｜備品耗材

適用狀況：軸承內圈故障（BPFI）

- 同規格軸承（本測試台為 6205 型深溝球軸承，實機請依銘牌確認）
- 軸承潤滑脂
- 油封 / 防塵蓋（拆過建議一併更換）

## 軸承內圈故障｜安全注意事項

適用狀況：軸承內圈故障（BPFI）

- 確實執行停機掛牌上鎖（LOTO），確認主軸完全靜止再作業
- 軸承加熱器操作時戴隔熱手套，加熱溫度勿超過 120°C
- 禁止用鐵鎚直接敲擊軸承，會在滾道留下壓痕造成新的故障

## 軸承內圈故障｜工時與人力

適用狀況：軸承內圈故障（BPFI）

更換單一軸承約 2~4 小時，1~2 人。含對心複校與試車約需半個工作天。
